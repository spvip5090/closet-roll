## 最終配点と計算方法（平易な説明）

内部軸（0–100）を先に計算し、総合価値（表示される100点）を重み付きで合成する。

| 内部軸 | 重み | 中身 |
|---|---|---|
| ラグジュアリー性 | 30% | 総額の対数スケールと各アイテム価格の対数スケールを半々。価格という1要素をここでのみ数える（二重計上回避） |
| アイテム単体の魅力 | 15% | attrs の appeal（street.points を土台に、柄・彩度・ブランド内価格位置で商品ごとに変動）を部位ウェイト（32/32/17/12/7）で加重平均 |
| 色彩・柄の相性 | 15% | 基礎60＋色数ロジック（無彩色のみ+6／アクセント1色+12、高彩度なら更に+6／3色以上は減点）＋柄ルール（上下で異なる柄 −12＝重大、同じ柄 +4、柄3点以上 −8）＋靴バッグ色リンク +4 等 |
| シルエット | 15% | 基礎60＋ペアルール（上下ボリュームの強弱 +7／両方過大 −7／防寒×サンダル −11＝重大／スポーツパンツ×ドレス靴 −10＝重大／季節の揃い +3 等） |
| スタイルの統一感 | 10% | 基礎58＋系統の揃い（3点 +7、4点 +12）＋系統ミックス相性表（カジュアル×ストリート +2、モード×個性派 −2 等）＋フォーマル度スプレッド（>55で −10）＋素材呼応（デニム上下 +5 等） |
| 全体の完成度 | 10% | 基礎60＋主役が脇役に支えられている +10／主張過多 −10／着用可能性の問題（肌着ボトムス −20＝重大、インナーがトップス −13＝重大、室内履き −11＝重大、紙袋バッグ −7）／問題なし +6 |
| 個性・華やかさ | 5% | 主張度（最大・平均）と写真の色の豊かさから算出。総合への寄与は小さいが分類の主軸 |

派生軸：ファッション性（色彩.30＋シルエット.25＋統一.20＋完成度.15＋魅力.10）、調和性（色彩.30＋シルエット.25＋統一.25＋完成度.20）、日常適性（調和・無彩色率・価格・主張度から）。

総合の較正：加重和を `50＋(raw−50)×1.55` で広げる（軸が60前後に寄るため。乱数ではない決定的な変換）。そのうえで条件付き調整：
- 重大な不調和1件につき −8（最大−20）。2件以上は45点上限。重大不調和がありファッション性≦ラグジュアリー性なら52点上限（＝高額でも壊滅的なら低得点）。
- 相乗：ラグジュアリー≥70＆ファッション性≥65で +5、ラグジュアリー≥85＆ファッション性≥68で更に +5、ファッション性≥75＆個性≥55で +3。
- 上限：ラグジュアリー<20なら74点上限、<35なら84点上限（安価だけでは満点近くにしない）。個性<28も84点上限（無難なだけでは表紙級にしない）。
- 決定的：同じ5点は常に同じ結果（シミュレーションで確認済み）。

分類（称号・コメントはこの分類と理由構造からのみ生成し、得点とは独立）：
重大な不調和あり→ 個性≥52なら「個性的だが成立していない」、他は「ダサい」。不調和なし→ 個性≥55＆ファッション性≥60「個性的でオシャレ」／ファッション性≥67「オシャレ」／調和性≥54「無難」／ファッション性<46「ダサい」／他は「無難」。
安価×無難は分類上「無難」にしかならず、称号・コメントのテンプレート自体が肯定的（日常適性・調和を評価し、低得点の理由を豪華さ・華やかさ不足と明示）。

理由構造：最良／最低の軸（最低軸はコメント用にラグジュアリーを除いた軸でも保持）、加点・減点ルール一覧、最良／最悪ペア（トップス×ボトムス等）、主役アイテム、を内部に持ち、第一印象（バナー）と得点下コメント（理由説明）は同じ構造から別役割で生成する。

## Phase 1：属性データ（attrs.js）のカバー率

生成：`build/gen_attrs.py`（名前キーワード＋写真のドミナントカラーを PIL で抽出、背景画素と肌色画素は減重み）。全1,318件・51KB。

| 属性 | カバー率 | 備考 |
|---|---|---|
| 色（名前由来・高信頼） | 504件 38.2% | 色コード BLK/WHT/RED 等＋日本語色名。採点では全重み |
| 色（写真由来） | 814件 61.8% | モデル着用写真では肌・背景に引っ張られる誤差あり。調和判定では重み0.55 |
| 柄 | 140件 10.6% | 名前キーワードのみ。残りは「柄なし証拠なし」として中立（無地断定はしない） |
| 素材 | 246件 18.7% | ビットマスク（デニム/レザー/ニット/スウェット/ナイロン/サテン系/綿麻） |
| シルエット（ボリューム） | 28件 2.1% | 名前に明記がある場合のみ。不足分は採点時のペアルール（名前正規表現、v1由来）で補完 |
| フォーマル度 | 112件 8.5% | 同上（不明は中立） |
| 季節シグナル | 67件 5.1% | 同上。季節の不一致は主にペアルールで検出 |
| 主張度・単体魅力・ブランド内価格位置 | 全件 | 既存データ（role/street.points/価格）＋柄・彩度等の商品別シグナルで算出。同ブランドでも一律にならない（例：UNIQLO 34件で appeal は11通り） |

不明値はすべて −1/0 で記録し、採点では中立扱い（推測で埋めない）。
